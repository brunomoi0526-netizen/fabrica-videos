# Fábrica de Videos — Expedientes Olvidados

Crea videos y Shorts para YouTube a partir de guiones (carpeta `guiones/`).
Cada vez que se añade un guion, GitHub Actions crea el video, 3 Shorts, la miniatura y los textos,
y los deja en **Releases**. La app del celular está en `docs/` (GitHub Pages).

Todo es gratis: voz edge-tts, imágenes de Wikimedia Commons, música generada.
